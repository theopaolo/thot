## Notes

`extraireMarkdown()` retire le gras et le code en ligne du texte de preuve, et tous les titres
deviennent des sections d'un seul niveau. Le lecteur ne peut donc pas montrer `reserver` en code
ni distinguer un `##` d'un `###`, alors que les cours de développement ont du code en ligne dans
presque chaque paragraphe.

Le texte et les offsets ne changent pas : chaque bloc porte en plus son niveau de titre et la
position de ses marques (gras, code en ligne). `enregistrer()` réécrit `blocs.jsonl` en place
quand seul ce fichier change, donc `thot reextraire` met les sources à jour sans révision à
certifier.

- [ ] `Partie` porte le niveau de titre et les marques, en offsets du bloc
- [ ] le lecteur rend les marques et les niveaux de titre, le sommaire suit les niveaux
- [ ] une citation qui coupe une marque reste surlignée
- [ ] fixture : gras, code en ligne, titres `##` et `###`
