## Notes

`assembler()` dans `src/core/document.ts` retire les espaces au début et à la fin de chaque
partie, blocs de code compris. La première ligne d'un bloc perd donc son indentation et les
suivantes la gardent :

```python
    if x:
        return 1
    return 2
```

devient `if x:`, puis `        return 1`, puis `    return 2`. Un `<pre>` lu par
`src/core/html.ts` subit le même sort. `docs/architecture.md` dit pourtant que les blocs de code
restent mot pour mot. L'audit l'a reproduit en lançant la fonction.

Corriger change le texte extrait des sources qui ont un tel bloc. Leur réextraction donnera une
révision à relire, comme le veut la règle 6.

## Travail

- [x] un bloc de code ne perd que ses lignes vides de tête et de fin
- [ ] compter sur `var/dev` les sources dont le texte change, pour savoir combien de révisions
      l'enseignant aura à relire

## Terminé quand

- [x] un test Markdown et un test HTML gardent l'indentation de la première ligne
