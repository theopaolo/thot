## Qualify the parser

Evaluate [python-pptx](https://python-pptx.readthedocs.io/en/latest/) as a worker subprocess
candidate. Check text, tables, grouped shapes, images and notes against representative decks.
Adding Python to the container is a deployment cost that must be justified by the extraction test.
Record a small protocol for normalised output if this candidate is retained. Avoid implementing
the whole Office format by hand.

[The notes API](https://python-pptx.readthedocs.io/en/latest/user/notes.html) provides access to
speaker notes. Their presence creates an access decision, since a deck may contain answer keys
or instructor-only guidance alongside learner-visible slides.

## Backend

- [ ] Detect PPTX packages, bound archive expansion and reject encrypted or macro-enabled formats.
- [ ] Preserve slide order, title, body, tables and image associations. Record hidden slides and
  make their inclusion an explicit review choice. Do not confuse XML shape order with proven
  visual reading order when several columns or grouped shapes are involved.
- [ ] Keep notes out of learner evidence by default. Materialise notes as a separate restricted
  resource, or give them a fully enforced access scope. Do not place private notes in a shared
  proof string and try to remove them only at display time.
- [ ] Preserve slide numbers in citations and distinguish slide text from notes. Ensure revisions
  keep slide references stable for older conversations.
- [ ] Report unsupported charts, SmartArt, equations, animations and embedded media. A visual
  preview is not proof that all visible content has been extracted.
- [ ] Qualify local slide rendering only if needed for reviewing text order or diagrams. Keep
  extraction and visual rendering separate, with resource limits on both.

## Frontend

Use a slide list or filmstrip with a readable extracted-text pane. Show notes and hidden-slide
status only to authorised reviewers. Provide the slide number and resource title in citations.
Offer original download when no faithful preview is available.

## Acceptance

- [ ] Fixtures include repeated headers, image-only slides, tables, grouped shapes, notes with
  an answer key, hidden slides and corrupt content.
- [ ] Teacher notes cannot appear in learner search, answers, citations or downloadable derivatives.
- [ ] Clicking a citation identifies the exact slide in the correct revision.
- [ ] Each unsupported element produces a useful limitation during review.
