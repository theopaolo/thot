## Notes

Six fichiers de tests dépassent 800 lignes : `tests/app_test.ts` (2 058), `tests/domaines_test.ts`
(1 889), `tests/acces_test.ts` (1 851), `tests/activites_test.ts` (1 036),
`tests/pratique_test.ts` (1 001) et `tests/office_test.ts` (892). Chacun réunit des sujets que rien
ne relie : pour lire les tests du dépôt, on ouvre aussi ceux des comptes et du chat.

Le découpage déplace les tests sans les modifier. Un test garde son nom, pour que l'historique et
les messages d'échec restent lisibles. Les aides qu'un fichier déclare pour ses seuls tests suivent
ces tests. Celles que plusieurs nouveaux fichiers partagent vont dans `tests/outils.ts`, ou dans un
fichier d'aides du même sujet si elles n'intéressent que lui.

[[arc-103]] réécrit les lignes d'import de ces fichiers et passe avant.
