## Notes

Beaucoup de cours techniques s'écrivent en Markdown : cours de développement, documentations,
fiches de procédure. Un fichier `.md` devient une source comme une page HTML : ses titres donnent
les sections, ses paragraphes, listes, tableaux et blocs de code restent du texte citable.

- [x] reconnaître un fichier Markdown à son extension et à un contenu UTF-8 valide, sans
  signature binaire
- [x] lire le titre dans le front matter, puis retirer le front matter du texte de preuve
- [x] faire des titres `#` les sections, sans prendre un `#` de bloc de code pour un titre
- [x] garder blocs de code, tableaux et blocs `mermaid` en texte, et nommer dans un
  avertissement les images liées qui ne sont pas jointes
- [x] accepter `.md` au dépôt, à l'import en ligne de commande et à la réextraction
- [x] fixtures : front matter, code avec `#`, tableau, image relative, octets non UTF-8
