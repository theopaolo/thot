## Notes

Un exercice porte une seule question : `Contenu` dans `src/core/activite.ts` tient une consigne,
une réponse attendue, des critères et un retour, et `tentatives.reponse` garde un seul texte. Les
enseignants envoient plutôt plusieurs questions à la fois
([ADR 0010](../../docs/decisions/0010-series-de-questions.md)).

Cette tâche garde le seul type actuel, la réponse rédigée. [[ped-105]] ajoute les autres.

- [x] le contenu d'un exercice devient une liste de questions, et la migration met chaque exercice existant dans une série d'une question
- [x] ajouter une question vide, la dupliquer, la monter, la descendre et la supprimer
- [x] une version et une relecture valent pour toute la série
- [x] une tentative garde une réponse par question et sa date de remise, si bien que l'élève enregistre, revient, puis remet
- [x] l'enseignant règle la correction : après chaque question, ou après la série, qui est le réglage par défaut
- [x] le corrigé d'une question ne sort du serveur qu'après sa remise, ou celle de la série selon le réglage
- [x] la page de l'élève annonce le nombre de questions et les numérote
- [x] après la correction, la page de l'élève montre pour chaque question sa réponse, la réponse attendue, les critères à cocher et le retour
- [x] l'aperçu de l'enseignant montre la série telle que l'élève la reçoit
- [x] `oublierSource()` vide les champs de chaque question qui citaient la source supprimée

L'explication d'étude reste une activité à part, sans question. En faire un texte à lire au début
d'une série reste possible plus tard.
