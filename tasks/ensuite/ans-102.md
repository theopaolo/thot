## Diagrams

- [x] Start with concept maps and simple process diagrams. Model output describes bounded nodes,
  relations and their evidence. Generate Mermaid syntax from the validated representation.
  Represent causal, chronological and thematic relations distinctly.
- [ ] Attach source references to factual nodes and relations. Keep proposed teaching connections
  labelled in both the diagram and its accompanying text. A valid diagram is not a verified claim.
  Références livrées. Une relation proposée sans preuve est refusée, à reprendre avec PED-101.
- [x] Use a pinned, locally bundled Mermaid renderer with strict security, HTML labels disabled,
  and no model-controlled directives, callbacks, links or external assets. Sanitize generated SVG
  before mounting it and test the chosen configuration against hostile fixtures. Le nettoyage du
  SVG ne tourne que dans un navigateur : il reste à le voir dans Helium.
- [x] Bound diagram size and rendering work. Parse/render failure shows an accessible text or
  structured-list fallback rather than breaking the entire answer.

[Mermaid's configuration documentation](https://mermaid.js.org/config/usage.html#securitylevel)
describes the security modes. These settings are a starting point for qualification, not a
substitute for validating model output and testing the rendering boundary.

## Mathematics

- [x] Qualify KaTeX for inline and display notation, including MathML output for accessibility.
  Use untrusted input mode, bounded expansion and size, and isolated macro state per render.
  Reject external resource and HTML-producing commands.
- [x] Keep the original expression available as text. Rendering a formula does not validate its
  reasoning, units or result. ANS-101 owns those evidence requirements.
- [ ] Prototype fractions, matrices, Greek symbols, units and long equations with a sans-serif
  math configuration. Check required font assets and fallback glyphs against the project's font
  policy before enabling the feature. Preserve the existing font for interface and prose.
  Les formules gardent les polices mathématiques de KaTeX, en WOFF2 seulement. Une configuration
  sans empattement reste à décider.
- [x] Render failures keep the rest of the answer usable and provide the expression with a clear
  explanation. Long equations scroll within their own container. L'explication est celle de
  KaTeX, en anglais, dans l'infobulle de la source affichée en rouge.

[KaTeX options](https://katex.org/docs/options.html) document trust, expansion limits and rendering
configuration. Select and test an explicit safe configuration rather than passing model-provided
options through.

## Frontend and code touchpoints

Load the renderers only when a block requires them. Render completed blocks once after HTMX/SSE
updates. Cancel abandoned rendering and preserve scroll and focus. Use local assets instead of a
third-party rendering service.

## Acceptance

- [ ] Hostile SVG, Mermaid directives, oversized graphs, recursive macros and URL commands cannot
  execute scripts, fetch resources or freeze the page beyond the configured budget.
- [ ] Diagram text equivalents and mathematical accessibility are checked with keyboard and
  assistive-technology-oriented inspection.
- [x] Each factual relation and formula can be traced to evidence or its explicit calculation.
- [ ] Helium screenshots cover long equations and diagrams on desktop and mobile.

## Livré

Les règles sont dans [architecture](../../docs/architecture.md#réponse-à-une-question), les
libellés dans [vocabulaire](../../docs/vocabulaire.md).

- Le bloc `schema` du profil général : des nœuds nommés, des relations `cause`, `suite` ou
  `theme`, chacune avec son affirmation. `ranger()` le borne, `texteMermaid()`
  (`src/core/notation.ts`) écrit le texte Mermaid. La liste des relations citées s'affiche
  toujours, le dessin vient au-dessus.
- Une formule `$…$` ou `$$…$$` ne se rend que si la citation de sa phrase l'écrit
  (`formules()`). KaTeX tourne avec `optionsKatex()`, que les tests éprouvent.
- `src/app/client/schemas.ts` et `src/app/client/formules.ts` ne se chargent qu'à la demande,
  après chaque contenu posé par htmx. DOMPurify vient de Mermaid, hissé par
  `pnpm-workspace.yaml`.
- Le lecteur dessine les blocs `mermaid` des cours Markdown au-dessus de leur code, sans front
  matter ni directive de l'auteur. Le langage d'un bloc de code est noté à l'extraction. Une
  source déjà extraite le gagne à sa prochaine extraction, sans nouvelle révision.
- Sur le jeu de développement, aucune question n'appelle de schéma
  ([évaluation](../../evaluation/README.md#reclasseur-et-génération)).
