## Notes

`pnpm check` dure une dizaine de secondes et couvre le format, le lint, les types, le build, la
frontière `core/`/`app/` et les 280 tests. Rien ne le lance hors du poste de travail : le dépôt
n'a pas de dossier `.github/`. Les tâches de correction qui suivent s'appuient sur lui, donc
celle-ci passe en premier.

Les tests d'extraction PDF appellent `pdftotext` : l'image du flux doit installer `poppler-utils`,
comme le `Dockerfile`.

## Travail

- [x] un flux GitHub Actions qui installe Node et pnpm aux versions de `package.json`, Poppler,
      puis lance `pnpm check` sur chaque push et chaque demande de fusion
- [x] le flux construit aussi l'image Docker, sans la publier

## Terminé quand

- [x] le flux a tourné au premier push de la branche et ses deux travaux ont réussi. Il lance
      `pnpm check`, qui sort en erreur dès qu'un test échoue, et GitHub arrête un travail sur une
      commande en erreur. Aucun commit cassé n'a été poussé pour le montrer
