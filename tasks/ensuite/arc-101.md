## Notes

Les fichiers de `src/app/routes/` gardent 39 requêtes SQL écrites dans leurs handlers. Une règle
écrite dans une route se recopie dans la suivante : les conversations l'ont montré, avec
`compte_id = ?` répété 18 fois avant `src/app/conversations.ts`.

- `prof.ts` (15) : changer les lecteurs en lot, les diapositives masquées ou les informations
  d'une source écrit dans la route, alors que `statuer()` et `supprimerSource()` le font dans
  `ingestion.ts`, avec la réindexation et les activités à revoir. Les listes de sources et de
  légendes à relire lisent aussi la base elles-mêmes.
- `eleve.ts` (6) : les pages élève remplissent leurs types de vue par des `SELECT` ad hoc. La
  ligne d'une source, ses images à légende certifiée et sa première image se répètent.
- `prof-eleves.ts` (5) : les élèves gérés et les liens d'inscription.
- `chat.ts` (4) : `perimetreRefuse` et `ideesPour` recroisent `FILTRE_ACCES` et
  `sourcesPerimetre` en JavaScript.
- `prof-depot.ts`, `comptes.ts`, `domaines.ts` (2 chacun), `activites.ts`, `media.ts`, `web.ts`
  (1 chacun).

Fait quand une route n'appelle plus `db.prepare` : chaque requête vit dans le module de
`src/app/` qui porte sa règle.
