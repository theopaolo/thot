## Notes

`extraireMarkdown()` garde une ligne par rangée de tableau, cellules séparées par « | ».
`texteDocument()` dans `src/app/vues/document.ts` met chaque bloc dans un `<p>`, donc les rangées
se collent en un paragraphe : « Smell | Signal | Action Nom opaque | data, temp… ». Vu dans Helium
sur « Code smells » du jeu développement. Les listes du même bloc ont le même défaut.

- [x] les lignes d'un bloc restent des lignes à l'écran, sans changer `document.txt` ni les offsets
- [x] une citation surlignée dans une rangée reste surlignée
