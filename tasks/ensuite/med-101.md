## Qualify processing

Use [FFmpeg](https://ffmpeg.org/ffmpeg.html) for local probing and audio preparation if the target
container supports the required formats. Evaluate one transcription engine on French and English
teaching samples, including names and technical terms. [whisper.cpp](https://github.com/ggml-org/whisper.cpp)
is a local candidate with timestamped output. Its presence on the candidate list does not establish
adequate speed or accuracy on the deployment hardware.

A remote transcription service is eligible only through an explicit instance policy. Reuse the
provider-policy work in [ING-108](ing-108.md) and [OPS-504](ops-504.md). Do not silently fall back to
remote processing when a local worker fails. Record measured runtime, resource use, error patterns,
supported languages and cost before enabling the selected engine.

## Backend

- [ ] Accept a bounded set of actual media formats. Validate duration, streams and codecs as well
  as bytes. Bound temporary disk use, decoder time, memory and output. Disable external protocols
  and embedded references during probing/transcoding.
- [ ] Keep the original and a manifest of derivatives. Extract speech with segment timestamps,
  language and processing provenance. Preserve offsets back to the original media when splitting
  recordings. Do not infer named speakers from automatic segmentation.
- [ ] Store transcripts as immutable revisions linked to the original. Corrections create a new
  revision and a new review decision. Search and citations use the selected revision's segments.
- [ ] Treat automatic transcription as unreviewed text. Shared learner answers use reviewed
  transcript evidence. Reviewers can inspect generated segments against playback. Personal study
  may explicitly use an automatic transcript with visible status and no expert-review claim.
- [ ] Handle silence, music-only recordings, overlapping speech, low-confidence passages and
  incomplete processing without fabricating a complete transcript. Transcription covers speech,
  not musical analysis or visual-only actions in a screen recording.
- [ ] Keep video-frame/OCR analysis as a separate, measured follow-up if the REAPER corpus needs
  it. An audio transcript must not imply that Thot understood every visible action.
- [ ] Make segment retries and cancellation safe. Carry absolute time offsets across retries and
  avoid duplicated text at segment boundaries. Include all derivatives in deletion and retention.

## Frontend

Show actual processing stages, duration, limitations and optional cost estimates based on a
configured tariff. A review screen connects transcript segments with playback and corrections.
Publication makes the transcript's status and supported evidence clear.

## Acceptance

- [ ] Speech samples retain correct absolute timestamps after chunking and retries.
- [ ] Silence and music-only samples do not produce accepted speech evidence.
- [ ] Correcting a transcript preserves an older conversation's cited revision and time range.
- [ ] An unapproved provider receives no recording, including through failure fallbacks.
- [ ] Measure throughput on the intended host before setting enabled duration and concurrency limits.
