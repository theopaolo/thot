## Notes

Les bornes du convertisseur PDF sont dans `src/core/pdf.ts` : délai, sortie, mémoire et arrêt
du processus. Linux applique une limite mémoire stricte, macOS surveille le RSS par sondage.
La suite de cette tâche couvre les autres extracteurs et les garanties de travail ci-dessous.

## Extension for EVO-001

Apply the same limits to Office parsing, media probing, conversion and transcription before
enabling those formats. This task owns execution bounds, while each parser task owns format fidelity.

- [ ] Bound input bytes, archive expansion, entries, XML depth, decoded image dimensions, media
  duration, output bytes and temporary disk use according to the operation.
- [ ] Run parsers with only their input/staging files, required executables and intended network
  access. Disable external document references, macros, shell interpolation and media URL protocols.
- [ ] Enforce deadlines with process-tree cancellation. Use deployment resource limits for actual
  memory/CPU bounds. A JavaScript timeout alone cannot constrain a subprocess's memory.
- [ ] Heartbeat leases during legitimate long jobs, then release or fail them with a specific
  cause. Cancellation and shutdown clean up partial output without deleting the last good revision.
- [ ] Preserve safe retry semantics and prevent a stale worker from committing after losing a lease.
- [ ] Qualify the limits on target hardware and expose only supported capacities in settings.

Touch [extractors](../../src/core/), [job execution](../../src/app/ingestion.ts),
[process permissions](../../src/main.ts), [CLI/test permissions](../../deno.json),
[container](../../Dockerfile) and [tests](../../tests/).

Completion requires fixtures for a stalled extractor, oversized expansion, malformed media,
cancelled process tree and restart after partial output. No real sensitive documents or paid model
calls belong in these deterministic tests.
