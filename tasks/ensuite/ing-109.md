## Qualify the parser

Use [Mammoth](https://github.com/mwilliamson/mammoth.js) as the first candidate because its
JavaScript API can be tested against the current runtime. It supports semantic conversion and
image extraction, but does not sanitise its HTML output. Prove runtime compatibility and extraction
fidelity before adding it as a production dependency. If it fails the corpus, assess a maintained
alternative and record the decision with measured failure cases.

## Backend

- [x] Detect an actual DOCX package using its container contents, not a ZIP signature alone.
  Reject encrypted documents, macro-enabled formats and unsupported archives explicitly.
- [x] Extract headings, paragraphs, lists, tables, embedded images, footnotes and hyperlinks into
  the common source representation. Define a documented policy for tracked changes and comments.
  Draft comments and deleted text must not silently become learner evidence.
- [x] Preserve document order and local image placement. Do not pass output through the current
  Pearltrees-specific HTML extraction path without qualifying everything it would discard.
- [x] Cite a section, paragraph or table cell. Do not invent stable page numbers for reflowable
  Word documents. Keep the original available to authorised users.
- [x] Warn about unsupported equations, floating text boxes or embedded objects. Unsupported
  content stays visible as an extraction limitation, not a successful empty extraction.
- [x] Disable external file resolution and resource downloads. Bound ZIP expansion, entry counts,
  XML parsing, image sizes, runtime and output size through ING-007.
- [x] Retain only normalised safe content and instance-owned assets. Never render converter HTML
  directly in a privileged application page.

## Frontend

Show the extracted reading view beside source metadata and warnings. Let reviewers inspect
tables, image positions and notes before publishing. Present structural citations rather than
promising an exact Word layout preview.

## Acceptance

- [x] Licensed or synthetic fixtures cover headings, nested lists, tables, notes, images, Unicode,
  tracked changes, malicious links, external references and a broken archive.
- [x] Expected text order and citation offsets hold after extraction and reindexing.
- [x] Known losses appear in the review interface before publication.
- [x] The batch uploader and CLI accept exactly the capabilities the parser actually supports.

## Livré

Mammoth, retenu par le propriétaire, lit le document (`src/core/docx.ts`). Son HTML devient des
passages et n'atteint aucune page : titres en sections, une ligne par élément de liste et par
rangée de tableau, notes de bas de page sous « Notes », liens réduits à leur texte. Le texte
inséré en modification suivie se lit comme accepté, le texte supprimé est écarté, les
commentaires restent hors du texte, et un avertissement signale chaque cas. La table de styles
intégrée au document est ignorée : elle pourrait faire sortir les commentaires. Une image garde sa
section (migration 0021) et sa légende accompagne le premier passage de cette section. Les
fixtures sont synthétiques, construites dans `tests/office_test.ts`. Aucun document réel n'a été
mesuré. Bornes : ING-007.
