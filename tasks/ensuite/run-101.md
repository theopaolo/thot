## Why

Deno development ends after one year of maintenance releases, see
[ADR 0007](../../docs/decisions/0007-passer-de-deno-a-node.md).

## Done

- [x] Port the code, tests and commands to Node.js 26, Vite+ and pnpm. Pin Node and pnpm in
  `package.json`.
- [x] Format the code with Oxfmt in an isolated commit listed in `.git-blame-ignore-revs`.
- [x] Configure Oxlint with a reason for each rule turned off. `vp check` passes without warnings.
- [x] Exit 0 after a requested stop.
- [x] Mark ADR 0003 as partly replaced by 0007 and 0007 as accepted.

## Acceptance

- [x] `pnpm check` passes with the same 100 tests as `deno task check` on ACC-102.
- [x] A real question on a copy of the pilot data returns an answer with verified citations.
- [x] In the container, the worker extracts a PDF. `SIGTERM` stops both processes. Killing the
  worker stops the server.
- [x] The server process fails to spawn a child process or reach the network without
  `--allow-net`. The worker fails to write outside the data directory with `node:fs`.
- [x] An existing `state.sqlite3` from the Deno build opens and migrates without change.
