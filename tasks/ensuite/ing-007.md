## Extension for EVO-001

Apply the same limits to Office parsing, media probing, conversion and transcription before
enabling those formats. This task owns execution bounds, while each parser task owns format fidelity.

- [ ] Bound input bytes, archive expansion, entries, XML depth, decoded image dimensions, media
  duration, output bytes and temporary disk use according to the operation.
- [ ] Run parsers with only their input/staging files, required executables and intended network
  access. Disable external document references, macros, shell interpolation and media URL protocols.
- [ ] Enforce deadlines with process-tree cancellation. Use deployment resource limits for actual
  memory/CPU bounds. A JavaScript timeout alone cannot constrain a subprocess's memory.
- [ ] Qualify the limits on target hardware and expose only supported capacities in settings.

Lease renewal, cancellation cleanup and stale-worker commits are handled by [[job-103]]. The other
limits land with the first new extractor that needs them: [[ing-111]], [[ing-109]], [[ing-110]] or
[[med-101]].

Touch [extractors](../../src/core/), [job execution](../../src/app/ingestion.ts),
[process permissions](../../src/main.ts), [CLI and test scripts](../../package.json),
[container](../../Dockerfile) and [tests](../../tests/).

Completion requires fixtures for a stalled extractor, oversized expansion, malformed media,
cancelled process tree and restart after partial output. No real sensitive documents or paid model
calls belong in these deterministic tests.

## Livré pour Word et PowerPoint

Les bornes de `BORNES`, `src/core/ooxml.ts`, s'appliquent à ING-109 et ING-110 : 25 Mo
déposés, 5 000 entrées, 50 Mo décompressés par entrée, 20 Mo par partie XML, 100 Mo pour
l'archive, 200 000 éléments XML, 10 Mo de texte extrait, 50 millions de pixels par image,
30 secondes. Tailles et nombre d'entrées se vérifient sur le répertoire central, avant toute
décompression. `zlib` décompresse chaque entrée sous sa taille annoncée, puis taille et CRC sont
vérifiés. La profondeur des groupes de formes est bornée à 32. Ni macro, ni fichier, ni adresse
externe n'est lu. Fixtures dans `tests/office_test.ts` : trop d'entrées, tailles annoncées
au-delà des bornes, bombe qui ment sur sa taille, archive tronquée, CRC faux, trop d'éléments,
texte trop long.

Mesuré sous macOS au plus près des bornes : 650 Mo de RSS pour un document Word, 430 Mo pour une
diapositive. L'extraction tourne dans le worker : le délai se vérifie entre deux étapes et
n'interrompt pas une analyse, et seule la limite mémoire du conteneur borne strictement la
mémoire (`docs/exploitation.md`). Les cases ci-dessus restent ouvertes pour les médias, pour un
processus d'extraction séparé qu'on puisse tuer, et pour la mesure sur le matériel cible.
