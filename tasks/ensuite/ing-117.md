## Notes

Depuis [[ing-115]], la table `images` ne porte que les images servies, et celles d'une version à
relire attendent dans `revisions/{n}/assets/` avec leur inventaire `images.jsonl`. Trois cas
restent hors de la relecture. Ils sont lus dans `src/app/ingestion.ts`, sans essai.

- La page de relecture d'une version en attente ne montre pas les images qu'elle apporte.
  L'enseignant certifie le texte, et les images arrivent chez les élèves sans qu'il les ait vues.
- Une extraction dont le texte est identique au texte servi mais dont les images diffèrent
  remplace les images servies en place : `traiter()` appelle `servirImages()` sans révision à
  relire.
- Une activité qui montre une image que la certification retire affiche une image cassée.
  `preuvesValides()` dans `src/app/activites/acces.ts` contrôle la source, pas l'image.
  `servirImages()` peut aussi redonner à une nouvelle image le numéro d'une image retirée, si
  c'était le plus grand : l'activité montrerait alors une autre image.

## Travail

- [ ] la relecture d'une version montre les images ajoutées et nomme celles qui partent
- [ ] des images différentes sous un texte identique font une version à relire
- [ ] une activité qui montre une image retirée devient à revoir, comme pour un passage
- [ ] le numéro d'une image retirée ne se réattribue pas
