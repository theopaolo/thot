## Notes

`docs/architecture.md` fait 808 lignes. `AGENTS.md` demande qu'un document ne garde que ce que le
code ne dit pas : une règle du produit, une raison, une contrainte extérieure. Des paragraphes
entiers décrivent pourtant ce qu'une fonction fait, étape par étape, pour l'extraction des
documents surtout. Chacun de ces paragraphes se périme dès que la fonction change.

Un paragraphe qui décrit une fonction devient un renvoi vers son fichier. Une règle, sa raison et
une contrainte extérieure restent. Certains paragraphes sont le seul endroit où une règle est
écrite : chaque coupe se vérifie d'abord dans le code et dans les tests.

## Travail

- [ ] relire chaque section et classer ses paragraphes : règle, raison, contrainte, ou description
      du code
- [ ] remplacer les descriptions par un renvoi au fichier

## Terminé quand

- [ ] le document fait environ la moitié de sa longueur
- [ ] aucune règle du produit n'a disparu : chacune se retrouve dans le document, dans un test ou
      dans un commentaire du code
