## Notes

Deux regroupements coexistent depuis [[dom-101]]. Le champ libre `sequence` des métadonnées
range la source sous le thème du même nom (`rangerLegacy()` dans `src/app/domaines.ts`), et le
périmètre de chapitre des élèves filtre encore sur ce texte (`p.chapitre` dans
`src/core/recherche.ts`). Les cases « Cours de rattachement » du dépôt choisissent un thème par
cours. Le formulaire de dépôt montre donc deux champs pour la même idée.

Le libellé réglable de [[cfg-101]] (« Séquence », « Module ») nomme le champ libre. Le menu des
thèmes garde « Thème ». Donner le même libellé aux deux montrerait deux champs « Module ».

- [x] faire du thème le seul regroupement : le dépôt choisit un thème par cours, le champ libre
  disparaît du formulaire
- [x] passer le périmètre de chapitre des élèves de `metadonnees.sequence` à `theme_id`, sans
  changer les adresses déjà partagées ni les périmètres des conversations
- [x] nommer les thèmes avec le libellé réglable partout : administration, filtres, dépôt, chat
- [x] garder `metadonnees.sequence` lisible pour les anciennes sources et l'import du pilote

## Livré

- Le dépôt et la modification d'une source n'ont plus le champ libre. Le menu de chaque cours
  porte le libellé réglable et propose « Directement dans le cours ». La bibliothèque, la file des
  légendes et les questions des élèves se rangent par nom de thème.
- La recherche ne filtre plus sur la séquence. La migration 0018 rattache au thème de sa séquence
  toute source rangée dans un cours sans thème, et donne aux conversations et aux questions le
  thème qui remplace leur chapitre. La colonne `chapitre` reste pour l'historique.
- `/eleve/sequences/:nom` redirige vers ce thème, ou vers `/eleve/sans-sequence`. Un `chapitre`
  envoyé par une page ou un lien d'avant les thèmes devient ce thème
  (`themeDuChapitre()`). Sans thème correspondant, la question est refusée.
- L'import CLI garde le nom du dossier comme séquence. Sans `--theme-id`, il range la source dans
  le thème de ce nom, avec ou sans `--cours-id`. La fiche enseignant affiche encore la séquence.
- La liste des ressources de l'élève se range par cours puis par thème.
- Reste hors de cette tâche : l'en-tête des passages indexés et la proposition d'informations du
  profil arts lisent encore la séquence. Une nouvelle source n'en a plus, son en-tête perd ce
  contexte. Le remplacer par le nom du thème change le texte indexé et demande une mesure
  ([[dom-104]]).
