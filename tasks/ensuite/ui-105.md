## Notes

Carnet de dev liste les chapitres d'un cours à gauche du texte. Le lecteur de Thot n'offre qu'un
retour vers « Ressources ». La liste des ressources d'un thème existe déjà dans la route
`/eleve/themes/:theme` (`src/app/routes/eleve.ts`), filtrée par `CITABLE`.

L'ordre est la question ouverte. Les cours de développement n'ont pas de séance, donc la page du
thème les range par titre : « Annexes » passe avant « Lire du code ». Le front matter des cours
porte une clé `order`, que l'import Markdown ignore aujourd'hui.

- [ ] décider l'ordre : `order` du front matter lu à l'import, ou nom de fichier
- [ ] les ressources du thème à gauche du texte sur grand écran, la ressource ouverte marquée
- [ ] liens vers la ressource précédente et la suivante en bas du texte
