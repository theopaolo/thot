## Notes

Le sommaire d'un cours (UI-107) dit ce que l'élève a lu. Thot ne gardait aucune trace de lecture.

Le lecteur marque une ressource lue quand la fin de son texte paraît à l'écran. Une lecture est une
donnée personnelle : seul l'élève la voit, et le worker la supprime avec ses échanges.

- [x] la table `lectures` (migration 0027)
- [x] `POST /eleve/sources/:id/lu` vérifie l'accès à la source comme le lecteur
- [x] la purge de `THOT_RETENTION_JOURS` supprime les lectures
- [x] aucune page d'enseignant ne montre les lectures
