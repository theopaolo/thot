## Backend

- [x] Move generation initiation out of the SSE connection lifecycle. A submitted turn persists a
  job. A worker performs it. SSE or bounded polling reports durable progress and results.
- [x] Extend the existing SQLite job approach with the reply job type and lease ownership.
  Renew leases during long work and reject writes from a worker that has lost ownership.
- [x] Separate interactive answer capacity from extraction/transcription capacity within the same
  instance. Use bounded workers or independent worker loops so a long recording cannot block chat.
  Avoid introducing a distributed queue for this deployment size.
- [x] Preserve per-conversation ordering while allowing bounded concurrency across conversations.
  The instance concurrency is a constant in `src/app/reponses.ts`.
- [x] Persist progress before notifying clients. Reconnect by reading current state or replaying
  stored events. An SSE disconnect must not duplicate the work or cancel it implicitly.
- [x] Implement explicit cancellation and bounded retries. Make output commits idempotent.
  A crash after a remote request may still cause a repeat provider charge unless the provider
  supports idempotency. Record attempts and expose that limit in operating guidance.
- [x] Snapshot source/configuration revisions and recheck authorisation before result publication.
  Purging a conversation cancels its jobs and prevents late writes from recreating its content.
- [x] Report queue time separately from provider processing. Preserve partial verified content
  only when its status and citations remain valid.
- [ ] Add media job types and per-account usage limits with [MED-101](med-101.md).
- [ ] Enforce provider rate limits beyond the bounded reply concurrency.
- [ ] Report ingestion progress through the same durable progress, in place of the HTMX polling
  of the teacher review queue (formerly JOB-102). The queue keeps its polling until then.

## Interface

Show queued, searching, generating, verifying, completed, cancelled and failed states using the
stages actually reported. Offer stop and retry where meaningful. Inactive conversations show
completion without moving focus or replacing the active conversation's content.

The same durable progress replaces the HTMX polling of ingestion progress in the teacher review
queue (formerly JOB-102).

## Acceptance

- [x] A reply completes after leaving its page and appears when the conversation is reopened.
- [x] Restart a worker, reconnect SSE and retry a request without duplicate result commits.
- [x] A cancelled or expired worker cannot overwrite a newer job attempt.
- [x] Run chat while a long media task is active and measure bounded interactive latency. An
  image caption that never returns stands in for media until MED-101.
- [x] Deleting or revoking access during processing cannot restore inaccessible content.
