## Notes

Certifier une révision (`statuer()` dans `src/app/ingestion.ts`) remet `suggestions_le` à vide
mais garde les questions vérifiées sur l'ancien texte. Elles restent proposées jusqu'au passage
du worker. Après le retrait des énoncés (ADR 0009), « Les user stories » a proposé pendant une
vingtaine de minutes « Quelles sont les trois user stories à écrire pour le persona ? », tirée
d'un atelier retiré. Si le worker échoue (OpenRouter 503), `marquerSuggestions()` marque la
source comme traitée et les anciennes questions restent.

- [ ] certifier une révision efface les questions suggérées de la source dans la même transaction
- [ ] un test : après une révision certifiée, `suggestionsDuPerimetre()` ne rend plus les anciennes questions
