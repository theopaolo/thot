## Notes

Dans un schéma de réponse, l'étiquette d'une relation chevauche son trait. Mermaid place
l'étiquette, avec la configuration de `src/app/client/schemas.ts`. Vu dans Helium sur le jeu
développement.

Mermaid dessine le fond de l'étiquette à 50 % d'opacité, donc le trait se lisait à travers le mot.
`themeCSS` le rend opaque dans `src/app/client/schemas.ts`. Vérifié dans Helium sur un schéma de
quatre relations.
