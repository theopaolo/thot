## Notes

Carnet-quiz (`~/Documents/Webworks/0-education/CarneDuDdev/carnet-quiz`) est l'outil que
l'enseignant utilise pour ses quiz en classe. Ses 11 quiz comptent 189 questions : 113 à choix
unique, 32 à choix multiple, 28 réponses à taper et 16 réponses rédigées. Comme son format décrit
déjà une série et que son `lib.js` corrige chaque type, Thot reprend ce modèle plutôt que d'en
inventer un second.

Une image et du code ne forment pas un type à part. Une image s'ajoute à n'importe quelle
question, et une question de code est une réponse rédigée qui porte un langage.

- [x] quatre types : choix unique, choix multiple de 2 à 8 options, réponse à taper avec ses variantes acceptées, et réponse rédigée, qui est l'exercice actuel
- [x] porter `textMatches`, `isCorrect`, `parseValue` et `validate` de `lib.js` dans `src/core/`, avec leurs cas de `lib.test.js`, et remplacer `plain` par `sansAccents` de `src/core/texte.ts`
- [x] corriger automatiquement les trois premiers types, comme le prévoit l'[ADR 0010](../../docs/decisions/0010-series-de-questions.md)
- [x] mélanger les options pour chaque élève, avec des lettres qui suivent l'ordre affiché
- [x] avec la correction après chaque question, l'indice s'affiche après une première erreur, et le second essai vaut 0,5 point
- [x] avec la correction après la série, chaque question n'a qu'un essai
- [x] une image sur n'importe quelle question, avec un texte alternatif obligatoire
- [x] l'image vient d'un dépôt de l'enseignant rangé avec l'activité, ou des images d'une source du cours, et la route qui sert un dépôt vérifie les droits sur l'activité
- [x] une réponse rédigée peut porter un langage : l'élève répond dans une zone à chasse fixe, et le corrigé s'affiche coloré par Shiki (`src/app/client/coloration.ts`), sans exécution
- [x] consigne, options et retour acceptent le code en ligne et les blocs de code entre accents graves, comme dans carnet-quiz
- [x] « Où chercher » renvoie à une ressource du cours, et l'import met le `lookup` de carnet-quiz dans l'indice
- [x] importer un quiz JSON de carnet-quiz comme activité en brouillon, dont tous les champs sont rédigés par l'enseignant
- [x] l'import ignore `trap`, `trapAnswers` et `timeLimit`, et la page de l'import le dit

QUIZ-001 compare déjà une réponse d'œuvre sans casse ni accents. Une fois `textMatches` porté, il
peut s'en servir.
